---------------------------- Projet Cinéma – En cours ----------------------------

📌 Contexte

Ce projet est réalisé dans le cadre de ma formation en Développement Web et Web Mobile.
Il a pour objectif d’approfondir mes compétences en PHP, programmation orientée objet, gestion de base de données, modélisation de données et architecture MVC, tout en découvrant les design patterns.


🖥️ Description du projet

Le projet consiste à créer un site web inspiré d’Allociné, que j'ai nommé Popcorn, permettant aux utilisateurs de trouver rapidement quel film regarder grâce à un choix réduit et simplifié.
L’exercice comprend :
  - La conception du site sur une architecture MVC.
  - La création d’un MCD pour organiser la base de données des films, genres et réalisateurs.
  - La mise en place de classes PHP orientées objet pour gérer les différentes entités.
  - L’exploration et l’intégration de design patterns pour structurer et optimiser le code.
Ce projet permet ainsi de combiner logique métier, organisation du code et interaction avec la base de données dans un contexte concret et fonctionnel.


🎯 Objectifs pédagogiques

- Approfondir la maîtrise du PHP orienté objet et de l’architecture MVC.
- Concevoir et relier une base de données relationnelle à une application web.
- Découvrir et appliquer des design patterns adaptés au projet.
- Développer un site web fonctionnel offrant une expérience utilisateur fluide et un sélecteur de films simplifié.


🚀 Compétences acquises

- Création et structuration de classes PHP et objets.
- Conception et mise en place d’un MCD et d’une base de données relationnelle.
- Organisation du projet en MVC et utilisation des design patterns.
- Gestion des interactions entre le front-end et le back-end.
- Développement d’une application web dynamique et modulable.
